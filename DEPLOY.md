# Deploying BarnBound to Render + Cloudflare (barn-bound.com)

The app (`web/`) deploys to **Render** as a Docker web service backed by **Render PostgreSQL**.
The domain **barn-bound.com** is registered at **Cloudflare**; we point its DNS at Render.

## 1. Deploy to Render (one-click Blueprint)

1. Go to <https://dashboard.render.com> and sign up / log in (use "Sign in with GitHub").
2. **New +** → **Blueprint**.
3. Connect the **`stikman28/barnbound`** GitHub repo (authorize Render if asked).
4. Render reads `render.yaml` and shows two resources to create:
   - `barnbound-db` (PostgreSQL)
   - `barnbound` (Docker web service)
   Review the plans/costs, then **Apply**.
   - Web service `starter` ≈ $7/mo (always-on). The DB starts on `free` (expires ~30 days) — upgrade it to **basic-256mb** (~$7/mo) before real launch.
5. First deploy takes a few minutes. It builds `web/Dockerfile`, then on start runs
   `prisma migrate deploy` (creates the tables) and launches Next.js.
6. When live, open the temporary URL Render gives you (e.g. `https://barnbound.onrender.com`)
   and check `…/api/health` → `{"ok":true,"db":"up"}`.

### (Optional) seed launch data on the live DB

In the Render dashboard → `barnbound` service → **Shell**:

```bash
npm run seed
```

Adds the 11 launch partners, 20 sample listings, and 3 demo sellers (password `password123`).

## 2. Point barn-bound.com at Render (Cloudflare DNS)

1. In Render → `barnbound` service → **Settings → Custom Domains**. `barn-bound.com` and
   `www.barn-bound.com` are already listed (from `render.yaml`). Render shows the exact DNS
   target for each — copy them. Typically:
   - `www` → **CNAME** → `barnbound.onrender.com`
   - apex `barn-bound.com` → **CNAME** → `barnbound.onrender.com` (Cloudflare flattens CNAME at the apex)
2. In **Cloudflare** → your domain → **DNS → Records**, add those records:
   - Type `CNAME`, Name `www`, Target `barnbound.onrender.com`
   - Type `CNAME`, Name `@`, Target `barnbound.onrender.com`
   - **Set both to "DNS only" (grey cloud) at first** so Render can validate and issue its TLS cert.
3. Back in Render, wait for the domains to show **Verified** and a certificate to be issued
   (usually a few minutes). Confirm `https://barn-bound.com` loads.
4. (Optional) In Cloudflare, set **SSL/TLS → Overview → Full (strict)**, then you may switch the
   records to **Proxied (orange cloud)** for Cloudflare's CDN/DDoS protection.

## Notes

- Render injects `PORT`; the container's start command binds to it.
- `AUTH_SECRET` is auto-generated by Render and stays stable across deploys.
- Every push to `main` auto-deploys (`autoDeploy: true`), running migrations automatically.
- Secure cookies require HTTPS end-to-end — keep Cloudflare on Full (strict) if proxied.
